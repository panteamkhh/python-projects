# Day 11 — Pandas Fundamentals

A small retail-sales analysis tool built with **pandas**, framed around
real business questions instead of isolated syntax exercises.

This is the first project of `data-basics/`, the second half of the
[20 Days of Python](../../README.md) repo, which shifts focus from
console apps and OOP fundamentals (`core-python/`) toward data
analysis.

---

## Business questions answered

- What's our total revenue and average order value?
- Which **region** brings in the most revenue?
- Which **product category** and which specific **products** are
  top performers?
- Does average order value differ across **customer segments**
  (Consumer / Corporate / Small Business)?
- How is revenue **trending month over month**?

---

## Key concepts used

- Loading and validating a CSV into a `DataFrame` (`pd.read_csv`,
  column-presence checks, `parse_dates`)
- Boolean indexing / filtering (`filter_orders`)
- `groupby` + aggregation (`sum`, `mean`, multi-aggregation with `.agg`)
- Sorting (`sort_values`)
- Time-based resampling (`resample("ME")`) for a monthly trend
- Clean OOP structure: one `SalesAnalyzer` class, each method
  answering one specific question, fully type-hinted and documented

---

## Dataset

`data/retail_sales.csv` is **synthetic but realistic**: 600 orders
across 4 regions, 3 customer segments, and 4 product categories,
generated with a fixed random seed for reproducibility.

It's generated by `generate_data.py` rather than shipped as a
black-box file, so the data-generation logic itself is transparent
and the dataset can be regenerated or scaled up/down:

```bash
python generate_data.py
```
